Mechanism

Core edges (dp = 0): at least one endpoint has no incoming neighbours — no alternative aggregation path exists. TGS retains these permanently without being told to.

Retired edges (dp > 0): all retired in a narrow window (epoch 40–60, immediately after warmup). Within this set, ρ(deg-product, τ) = −0.987 — hub×hub edges (dp up to 110) retire first because they have many redundant parallel paths; once GNN representations mature, these edges add no marginal information. This is not a learned heuristic: it emerges from gradient-based influence estimation applied to the graph's structure.

Same-class gradient: same-class fraction rises from 0.14 (earliest retired) to 0.33 (latest retired), then drops to 0.11 for core. Cross-class hub edges are the first declared redundant — consistent with the CV→τ* interaction (b_A − b_B = +113.6, p = 0.0001): heterophilous hub edges carry mixed signal whose redundancy is detected sooner after maturation.
